🦴 Het bekken (os coxa)
Het bekken bestaat uit drie botten die samen het os coxa vormen.
🧠 Kernpunten examen:

Os ilium (darmbeen) = grote vleugels bovenaan; crista iliaca = de bovenkant
Os ischium (zitbeen) = onderste deel; tuber ischiadicum = het zitpunt (hamstrings hechten hier)
Os pubis (schaambeen) = voorzijde; verbonden via symphysis pubis
Os sacrum (heiligbeen) = verbindt via SI-gewricht (art. sacroiliaca) met os ilium
Acetabulum = de heupkom (gevormd door alle drie de botten samen)
Os coxa = heupbeen = os ilium + os ischium + os pubis samen
